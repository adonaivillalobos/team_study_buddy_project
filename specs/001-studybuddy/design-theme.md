# StudyBuddy Design Theme

## Color Palette

StudyBuddy will use a clean, modern color palette designed to provide good visual contrast and a student-friendly appearance.

| Purpose | Color | Hex Code |
|---|---|---|
| Primary | Blue | `#375ECB` |
| Accent | Orange | `#FF7310` |
| Background | Light Gray | `#F8FAFC` |
| Success | Green | `#007F2E` |
| Error | Red | `#CC0303` |
| Text | Dark Gray | `#1F2937` |

### Color Usage

- **Primary Blue (`#375ECB`)** will be used for primary actions, navigation elements, and important interface elements.
- **Accent Orange (`#FF7310`)** will be used for secondary highlights and calls to action.
- **Background (`#F8FAFC`)** will provide the main page background.
- **Success Green (`#007F2E`)** will indicate completed or successful actions.
- **Error Red (`#CC0303`)** will indicate errors or destructive actions.
- **Dark Gray (`#1F2937`)** will be used primarily for readable text and headings.

## Typography

StudyBuddy will use two complementary fonts to create a clear and modern visual hierarchy.

### Headings

**Montserrat**

Montserrat will be used for:

- Page titles
- Section headings
- Card headings
- Important labels

Montserrat provides a strong and modern appearance for headings.

### Body Text

**Open Sans**

Open Sans will be used for:

- Paragraphs
- Descriptions
- Form labels
- Navigation text
- General interface text

Open Sans provides clear and comfortable readability for longer text and application content.

## Layout and Spacing

StudyBuddy will use a clean, modern, and student-friendly layout.

### Layout

- The application will use a responsive, mobile-first design.
- Content will be centered within a maximum width of approximately 1200px.
- Pages will use clear sections and consistent alignment.
- Cards will be used to organize related information.
- The interface will use subtle shadows and light borders to separate content.
- Navigation and common interface elements will remain consistent across pages.

### Border Radius

- Cards will use a 12px border radius.
- Buttons and form inputs will use an 8px border radius.

### Spacing

StudyBuddy will use an 8px-based spacing system for consistent layout spacing:

- 8px - Small spacing
- 16px - Standard spacing
- 24px - Medium spacing
- 32px - Large spacing
- 48px - Section spacing

The spacing system will be applied consistently between sections, cards, form fields, and other interface elements.

## Shared UI Library

StudyBuddy will use reusable UI patterns and components to keep the application consistent across all pages.

The shared UI will include:

- Primary and secondary buttons using the project color palette.
- Consistent form inputs and labels.
- Reusable cards for study plans and progress information.
- Progress bars for displaying completion percentages.
- Consistent navigation and footer elements.
- Success and error states using the designated colors.
- Consistent spacing, typography, borders, and rounded corners.

The shared UI components will be implemented using Tailwind CSS and reused throughout the application.
